ANHUI - descoberta e configuracao ID 2 / 9600 / 8N1

Nao precisa instalar Python para usar o executavel Windows x64.
Conecte somente UM transdutor ao conversor RS485. Feche outros programas
que estejam usando a porta. Use este programa apenas com o modelo cujo
protocolo corresponde ao manual incluido.

Abra PowerShell na pasta do executavel. Troque COM7 pela porta real:

Apenas localizar, sem alterar:
.\Anhui_ID2_9600.exe --port COM7 --scan-only

Localizar e configurar ID 2 / 9600 / 8N1:
.\Anhui_ID2_9600.exe --port COM7 --new-id 2

Busca padrao: IDs 1..247, nas oito velocidades do manual, em 8N1.
Uma busca sem respostas demora aproximadamente 14 minutos ou mais.
O manual menciona IDs ate 255; este programa limita a faixa unicast
Modbus convencional a 1..247. Nao localiza IDs 248..255.
Sem argumentos, apenas exibe ajuda. --scan-only nunca escreve.
Logs ficam na subpasta logs ao lado do executavel.
O programa altera somente se encontrar exatamente uma configuracao valida.
Confira SUCESSO no log; a leitura confirma ID/baud e medicao apos as escritas.
Nao desconecte durante a alteracao. Em caso de falha, consulte o log para
saber se o sensor ficou com ID novo e velocidade antiga.

baud no endereco bruto 0x0001; codigo 3 significa 9600; formato 8N1.
